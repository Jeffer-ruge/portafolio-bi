# Recursos y procedencia

| Recurso | Procedencia y uso |
| --- | --- |
| Perfil, trayectoria y formación | Hoja de vida actualizada y datos de LinkedIn recuperados durante el trabajo previo. Las fechas de Xorex siguen las fechas contrastadas al actualizar Computrabajo. El extracto editorial usa estos hechos sin métricas inventadas. |
| Paleta | Referencia visual y especificaciones del brief. Extensiones tonales en los tokens para superficie y contraste. |
| Núcleo de portada | Render original generado para el proyecto. WebP a dos resoluciones. |
| Escena WebGL | Geometría procedural original en Three.js y React Three Fiber. El script de Blender reproduce el concepto sin depender del render de portada. |
| Ilustraciones de casos | Composiciones CSS abstractas. No contienen capturas internas ni datos de clientes. |
| Currículum | PDF original indicado por el usuario, `HV_Jefferson_Zambrano_Analista_BI_Automation.pdf`. |
| Iconos | Lucide, licencia ISC. |
| Tipografías | Geist y Space Grotesk, licencia SIL OFL cuando se sirven desde los paquetes Fontsource. |
| Raylight | Documentación de MCP revisada. Sin conexión disponible en la sesión. Guiones en `docs/raylight/`. |
| Componentry | Scroll Split Card, importado del registro oficial y adaptado al sistema visual del portafolio. Licencia MIT incluida en `docs/componentry-LICENSE.txt`. Se reutiliza Motion del proyecto y se usa una imagen local. |
| Prichard | Referencia de atmósfera, navegación flotante y ritmo entre escenas. La escena WebGL, la composición y los textos son propios. |
| Recent Design y skills | Referencia editorial y catálogo de skills. Guía aplicada: Emil Kowalski, especialmente movimiento con propósito y reducción de efectos frecuentes. |

Pendientes de insumos: retrato profesional, capturas o demos públicas aprobadas, credenciales públicas de cursos, cuenta conectada de Raylight y dominio definitivo de Vercel. Los casos prescinden de materiales operativos, datos internos o vínculos sin verificar.
